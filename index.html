How this page works

A finding is added only when it has been reported to the maintainers and the reference resolves. Each entry records which probe it became, or which limit it cannot be probed by. Probe sets are versioned, so a later probe never rewrites an earlier entry.

The scanner tests authorization-server properties on a running endpoint. Three of the findings here sit outside that scope: sandbox isolation, policy enforcement and argument handling. They're on the page because they're real and they have advisories, not because the scanner found them. Where a finding has a half a prober can reach, like the issuer on row 4, the other half is listed as a declared limit.

This is a record of reports, not a claim that any system is secure.
